## p.1 개요

- 전체 메뉴에 "3D방 꾸미기" 메뉴를 추가한다. 위치는 "인테리어 상담" 메뉴 바로 아래.
- 사용자는 3D방을 만들고 이름을 붙여 저장할 수 있다.
- 대상 플랫폼: AOS, iOS (앱 버전 6.12.0 이상)
- 로그인 사용자만 이용할 수 있다.
- 비대상: 태블릿 레이아웃, 웹, 가구 배치 기능(v1.1 예정)

## p.2 3D방 꾸미기 온보딩

**진입**: 전체 메뉴 > 3D방 꾸미기 선택 시, 최초 진입이면 온보딩 화면을 노출한다.

**구성**
- 타이틀 문구: "스마트폰에서 손쉽게 내 방을 계획해보세요"
- 버튼: "3D 방꾸미기 시작하기"
- 우측 상단 닫기(X) 버튼

**동작**
- "3D 방꾸미기 시작하기" 선택 시 신규 3D방 편집 화면으로 이동하고 튜토리얼(1/5)을 노출한다.
- 버튼을 선택하지 않으면 5초 후 신규 3D방 편집 화면으로 자동 이동한다.
- 닫기(X) 선택 시 전체 메뉴로 돌아간다.
- 비로그인 상태로 진입하면 로그인 화면으로 이동하고, 로그인 완료 후 온보딩 화면으로 돌아온다.

## p.3 신규 3D방 편집

**튜토리얼**
- 편집 화면 최초 진입 시 튜토리얼을 정상 노출한다.
- 1/5 ~ 4/5 단계는 "다음" 버튼, 5/5 단계는 "완료" 버튼을 제공한다.
- "건너뛰기" 선택 시 튜토리얼이 닫힌다.

**방 이름**
- 방 이름 입력창 (필수), 1~20자, 한글·영문·숫자·공백 허용
- 플레이스홀더: "방 이름을 입력해주세요"

**저장**
- "저장" 버튼은 방 이름이 입력되면 활성화된다.
- 저장 성공 시 "방이 저장되었습니다" 토스트를 노출하고 잠시 후 내 3D방 목록으로 이동한다.
- 저장 실패 시 에러 메시지를 노출한다.

**이동**
- 편집 화면에서 뒤로가기 시 전체 메뉴로 이동한다. (온보딩 화면으로 돌아가지 않는다)

## p.4 내 3D방 목록

- 저장한 방을 목록으로 보여준다. 정렬은 기존 "스크랩북" 목록과 동일하다.
- 각 항목: 썸네일, 방 이름(최대 15자), 마지막 수정일(YYYY.MM.DD)
- 저장한 방이 없으면 "아직 만든 방이 없어요" 문구와 "새 방 만들기" 버튼을 노출한다.
- 목록 상단 "새 방 만들기" 버튼 선택 시 신규 3D방 편집 화면으로 이동한다.
- 방은 최대 10개까지 만들 수 있다. 10개 보유 상태에서 "새 방 만들기" 선택 시 "방은 최대 10개까지 만들 수 있어요" 팝업을 노출한다.
- 목록에서 방 선택 시 해당 방의 편집 화면으로 이동한다.
