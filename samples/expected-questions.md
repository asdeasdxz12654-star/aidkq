## 답변 붙여넣기용
```
Q(1): 재진입 시 온보딩 없이 내 3D방 목록으로 이동한다.
Q(2): 5초 이전에 버튼 선택 시 타이머는 취소되고 편집 화면으로 1회만 이동한다.
Q(3): 튜토리얼은 편집 화면 위에 딤 처리 + 말풍선으로 노출되고, 상단에 단계 "1/5"가 표시된다.
Q(4): 건너뛰기 후에는 튜토리얼을 다시 노출하지 않는다(완료와 동일).
Q(5): 토스트 노출 2초 후 내 3D방 목록으로 이동한다.
Q(6): 저장 실패 시 토스트 "저장에 실패했어요. 다시 시도해주세요"를 노출하고, 입력한 방 이름은 유지한다.
Q(7): 정렬은 최근 수정순(내림차순)이다.
Q(8): 방 이름 입력은 최대 20자. 목록에서는 15자를 초과하면 말줄임(…)으로 표시한다.
Q(9): 저장 처리 중에는 저장 버튼이 비활성화되어 방은 1개만 저장된다.
Q(10): 3D방 로딩 실패 시 팝업 "네트워크 연결을 확인해주세요"와 "다시 시도" 버튼을 노출한다.
Q(11): 백그라운드에서 복귀하면 5초 타이머를 처음부터 다시 센다.
```
02가 매긴 질의 번호와 위 번호는 다를 수 있으니, 붙여넣을 때 02의 Q-xx 번호로 바꿔 넣는다.
