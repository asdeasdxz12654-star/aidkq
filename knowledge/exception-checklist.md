# 예외 체크리스트 (전 화면 고정 적용)

테스트 조건 도출(STEP 3) 시 **모든 대상 화면에 기계적으로 대입**한다.
항목마다 `적용 / 해당 없음(사유) / 질의 필요` 중 하나로 판정하고, 판정 결과를 빠짐없이 남긴다.
기획서에 동작이 정의돼 있지 않은데 적용 대상이면 TC가 아니라 **질의**로 분류한다.

| 코드 | 항목 | 점검 포인트 |
|---|---|---|
| EX01 | 뒤로가기 (하드웨어·제스처·상단 버튼) | 이동 대상 화면, 입력값 유지 여부, 확인 팝업 여부 |
| EX02 | 홈 버튼 / 앱 백그라운드 전환 후 복귀 | 타이머 초기화·유지, 입력 상태 유지, 재인증 여부 |
| EX03 | 화면 회전 / 폴더블 전개 | 레이아웃, 입력값·스크롤 위치 유지 |
| EX04 | 네트워크 끊김 / 느린 네트워크 / 요청 타임아웃 | 오류 문구, 재시도 수단, 로딩 표시 |
| EX05 | 버튼 연속·중복 탭, 처리 중 재탭 | 중복 요청·중복 화면 이동 방지 |
| EX06 | 권한 거부 및 재요청 (카메라·저장소·위치·알림 등) | 거부 시 안내, 설정 이동, 재요청 시점 |
| EX07 | 로그인 만료 / 비로그인 진입 | 로그인 유도, 로그인 후 복귀 위치 |
| EX08 | 빈 데이터 / 대량 데이터 | Empty 화면, 페이징, 성능 |
| EX09 | 긴 문자열 / 특수문자 / 이모지 | 말줄임, 줄바꿈, 입력 허용 여부 |
| EX10 | 딥링크·푸시로 직접 진입 | 진입 화면, 뒤로가기 시 스택 |
| EX11 | 저사양 기기 / 최소 지원 OS 버전 | 기능 제공 여부, 미지원 안내 |

## 판정 예시
```
화면: 3D방 꾸미기 온보딩
EX01 적용     — 뒤로가기 시 전체 메뉴 복귀 (기획서 p.3 명시)
EX02 질의 필요 — 백그라운드 복귀 시 5초 타이머 재시작 여부 미정의 → Q
EX03 해당 없음 — 세로 고정 화면 (기획서 p.1 환경)
EX05 적용     — 버튼 연속 탭 시 편집 화면 1회만 진입 (규칙집 NAV-03)
```
