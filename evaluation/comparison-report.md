## 4. TC 비교 (03b 단계)
정답지 TC 1건마다 AI TC 중 같은 것을 검증하는 TC를 찾아 대응시킨다.

| 정답지 ID | 대응 AI TC ID | 판정 | 차이 |
|---|---|---|---|
| MENU-001 | | 일치 / 부분 / 누락 | |
| ... | | | |

판정 기준
- **일치**: 같은 조건을 검증하고 기대결과가 판정 가능하며 근거가 같다 (문구 표현 차이는 무시)
- **부분**: 같은 조건이지만 기대결과 일부 누락, 입력값 모호, 병합·분리 단위가 다름
- **누락**: 대응하는 AI TC가 없음

| 지표 | 수치 | 목표 |
|---|---|---|
| 정답지 커버리지 (일치+부분) / 22 | % | |
| 일치율 (일치 / 22) | % | |
| 초안 채택률 (수정 없이 사용한 AI TC / 전체 AI TC) | % | 60% 이상 |
| 추가 커버리지 (정답지에 없는 유효 AI TC) | 건 | 5건 이상 |
